# Data science projects

Side projects I built while doing the [Applied Data Science with Python](https://www.coursera.org/specializations/data-science-python) specialization on Coursera. Each course ended with a harder open task, and I picked topics from energy and life cycle assessment for them.

- [semantic search](semantic%20search/) matches free text queries to ecoinvent product names with sentence embeddings.
- [poland_gas_trade_ml](poland_gas_trade_ml/) splits Poland's natural gas imports that Eurostat reports as aggregated regions back into countries.
- [electricity_pagerank](electricity_pagerank/) ranks European countries in the electricity trade network with PageRank.

No input data is included. Each project's README says where to get it.

These are learning projects, so expect rough edges.
